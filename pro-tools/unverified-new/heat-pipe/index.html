使用说明与依据



1. 适用范围


本工具用于热管（两相闭式热虹吸管 / 吸液芯型热管）的最大传热能力 Qmax 工程估算，同时给出毛细限、声速限、携带限、沸腾限四个传热极限，取最小值作为该工况下的极限传热能力，并指出控制极限。不含启动特性（冷冻启动）、不凝性气体影响、以及非稳态工况。



2. 计算公式（Cotter 传热极限理论）




极限公式说明


毛细限 QcapQ = [2σ/rc − ρl g Lt sinφ] / [ μlLeff/(K Aw ρl hfg) + μvLeff/(8 Av ρv hfg) ]吸液芯毛细压头与液/汽两相流动阻力平衡；分母为两相流动阻力项


声速限 QsonQ = Av ρv hfg [γ Rv Tv / (2(γ+1))]0.5蒸汽在管内达到声速（壅塞），一般仅低温启动时出现


携带限 QentQ = Av hfg [σ ρv / (2 rhv)]0.5汽流剪切把液滴从吸液芯表面卷走（Weber 数判据），rhv=Dv/2


沸腾限 QboilQ = [4π λeff Le Tv / (hfg ρv ln(Di/Dv))] × (2σ/rb − 2σ/rc)吸液芯内汽泡核化导致局部蒸干


有效长度 LeffLeff = 0.5 Le + La + 0.5 Lc标准热管有效长度定义





3. 物性数据取值与出处


内置物性表为工质饱和线上的工程手册典型值（量级参考 ASHRAE Handbook / VDI Heat Atlas / 热管专著附录），按工作温度线性插值。表中数值为取整后的工程值（约 ±5% 量级），精确设计应以 NIST REFPROP 或厂家物性数据为准——因此本工具把 Dᵢ、Dᵥ、K、rc、ε、λeff、rb 全部开放为可覆盖输入。




工质适用温区备注


水30 ~ 250 °C品质因数最高、相容性最好，但低温冻结、高温高压


氨−60 ~ 100 °C低温段首选，与铝不相容（须用钢）


丙酮0 ~ 120 °C中等温区，与铝相容性较好


甲醇−10 ~ 130 °C低温启动性好，有毒


乙醇0 ~ 130 °C与丙酮相近，潜热偏低





4. 输入校验规则


    

  • 所有输入不得为空、必须为有效数字并在允许范围内，否则显示中文错误提示。
    • 

  • 必须满足 Dv < Di，否则无吸液芯截面。
    • 

  • 工艺温度须落在该工质适用温区，超出时给出警告（物性外推不可靠）。
    • 

  • 毛细限分母出现负值或非有限值时，判为「该倾角下毛细压头不足以克服重力」并提示。
    •
