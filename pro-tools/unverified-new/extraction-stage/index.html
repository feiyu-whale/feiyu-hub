液液萃取级数计算器

单级 / 多级逆流萃取 · Kremser 方程 · 溶剂比优化

使用说明
1. 选择物系预设可快速填入参考 K，也可直接手填实测或文献 K 值。
2. 相比 R 为有机相（溶剂）与水相（料液）体积流量之比；萃取因子 E = K·R。
3. 输入理论级数 n 得到实际萃取率；输入目标萃取率得到所需级数，并反算该级数下的最小相比 R_min。
4. 温度修正为线性经验模型，默认系数 0 即不做修正，需按实测数据自行标定。
5. 模型假设：y = K·x 线性平衡、稀溶液、两相体积近似可加、溶剂为新鲜溶剂（y_S = 0）。
公式出处：Kremser 方程（多级逆流萃取），见 Perry 化工手册 8th ed. Sec.15（Liquid-Liquid Extraction）；R. E. Treybal, Mass-Transfer Operations, 3rd ed.。φ=(E^(n+1)−E)/(E^(n+1)−1)，E=1 时 φ=n/(n+1)；n=ln[1+(E−1)/(1−φ)]/lnE−1；单级 φ=E/(1+E)；R_min=1/K（E=1，需无穷多级）。物系预设 K 值与本工具的温度修正系数均为行业经验值，未经标准核对。
