使用说明与依据



1. 适用范围


本工具用于饱和蒸汽系统的疏水阀初步选型：由蒸汽压力查饱和温度与汽化潜热，计算运行凝结水量、启动预热凝结水量、蒸汽管道散热凝结水量，乘以安全系数得到所需排量，再按孔口出流公式估算最小流通直径。不含过热蒸汽、不含闪蒸蒸汽回收系统设计、不含排量—压差曲线逐台选型。



2. 计算公式




项目公式说明


运行凝结水量W = Q × 3600 / rkg/h；Q 为热负荷 kW，r 为汽化潜热 kJ/kg


启动预热凝结水量Ws = m·cp(Ts−T0) / (r·th)kg/h；m 为金属质量，th 为加热时间（换算成小时）


管道散热凝结水量Wp = q′·L·3.6 / rkg/h；q′ 单位 W/m


所需排量Wreq = Wmax × SFWmax 取运行与启动两者较大值，再加管道散热


孔口出流W = 3600·Cd·A·√(2Δp·ρ)kg/h；A 为流通面积 m²，Δp 为阀前后压差 Pa，Cd=0.6


最小流通直径d = √(4W / (3600·Cd·π·√(2Δp·ρ)))m；再由标准口径圆整





3. 参数取值与出处




参数取值 / 来源说明


饱和蒸汽性质IAPWS-IF97 标准值内置表按绝对压力 0.1~4.0 MPa 共 14 个点，线性插值；温度与潜热为国际水和水蒸气性质协会标准值


安全系数 SF浮球 1.5 / 倒吊桶 2 / 圆盘 2 / 热静力 X 元件 2 / 双金属 3~5来源：TLV《疏水阀选型：安全系数和产品运行周期成本》推荐最小安全系数表。连续排水型（浮球）取值最小；间歇排水型因运行间歇需更大缓冲


孔口流量系数 Cd0.6锐边孔口水力出流工程常用值（0.6~0.62 区间），本工具取下限偏安全


凝结水密度 ρ默认 900 kg/m³按饱和温度下水的密度取工程值，可覆盖


碳钢比热 cp0.46 kJ/(kg·K)碳钢常温至 200°C 区间工程平均值





4. 输入校验规则


    

  • 所有输入不得为空、必须为有效数字并在允许范围内。
    • 

  • 必须满足 P₁ > P₂（阀前后压差为正），否则疏水阀无推动力。
    • 

  • 蒸汽压力须在 0.05~4.0 MPa(表压) 范围内，超出时给出警告（物性外推不可靠）。
    • 

  • 背压比 P₂/P₁ 过高（>50%）时给出警告：机械型疏水阀在高压比下排量急剧下降。
    • 




5. 免责说明


本工具为工程估算辅助工具。实际选型必须以疏水阀厂家的排量—压差曲线（不同口径、不同过冷度）为准，并考虑凝结水回收背压、水锤、污物堵塞、冻堵风险。计算结果仅供方案比选。
