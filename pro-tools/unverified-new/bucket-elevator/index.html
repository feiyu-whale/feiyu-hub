公式与依据
① 输送量 Q = 3.6·(i/a)·v·ρ·ψ，i/a 为线容量（L/m）——《运输机械设计选用手册》（化学工业出版社）
② 净提升功率 P₀ = Q·g·H/3600（g=9.81 m/s²）；轴功率 P_sh = K·P₀/η，K=1.0~1.6 为运行阻力系数（含链条/胶带与滚筒阻力、掏取阻力）
③ 牵引力 F = 1000·K·P₀/v（N）
④ 头轮转速 n = 60v/(πD)；极点距 h = 895/n²（m）。h≤R 为离心式、R<h≤1.5R 为混合式、h>1.5R 为重力式，R=D/2
⑤ 电机功率按 GB/T 755《旋转电机 定额和性能》标准功率等级向上圆整，并留 10% 裕量
⑥ 装满系数 ψ：粉状 0.78 / 颗粒 0.70 / 块状 0.60；带速上限粉 1.6 / 颗粒 2.0 / 块 1.5 m/s —— 本参数为行业经验值，未经标准核对
⑦ 料斗型式 Q（浅斗）/ S（中深斗）/ H（深斗）参照 JB/T 3926《垂直斗式提升机》型式与基本参数

使用说明

1. 输入：提升量 Q、提升高度 H、物料容重 ρ、物料特性（决定装满系数 ψ 与带速上限）、头轮直径 D、斗间距 a、带速 v、阻力系数 K、传动效率 η。

2. 输出：所需线容量 i/a、单斗容积 i、推荐斗型、净提升功率、轴功率、圆整后电机功率、牵引力、头轮转速、极点距 h 及 h/R、卸料方式判别。

3. 卸料判别：极点距 h=895/n² 与头轮半径 R 比较。h≤R 时离心力主导为离心式，适合粉状/小颗粒且要求带速较高；h>1.5R 时重力主导为重力式，适合块状磨琢性物料；两者之间为混合式。

4. 输入校验：任一输入为空、非数字、负数或超范围，均在结果区给出中文提示，绝不输出 NaN。

5. 适用边界：本工具用于初步选型估算。胶带/链条强度、轴功率精确校核、启动与堵料工况、料斗实际装满率须按厂家样本及 JB/T 3926《垂直斗式提升机》系列标准复核；ψ 与带速上限为行业经验值，未经标准核对。

6. 精度：电机功率按 GB/T 755 标准等级向上圆整并留 10% 裕量，结果为工程量级参考值。
