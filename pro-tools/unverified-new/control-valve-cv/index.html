使用说明

1. 依据标准

IEC 60534-2-1《工业过程控制阀 第2-1部分：流通能力 安装条件下流体流量的计算公式》，等同采标为 GB/T 17213.2。可压缩流体常数 N6=63.3（W: lb/h，P: psia，ρ: lb/ft³）及液体公式常数取自 Fisher/Emerson《Control Valve Handbook》第 5 版相关章节。

2. 液体

Kv = Q·√(SG/ΔPeff)，Cv = 1.156·Kv（Q: m³/h，ΔP: bar）。

阻塞流判据 ΔP_allow = FL²·(P1 − Ff·Pv)，Ff = 0.96 − 0.28√(Pv/Pc)；当 ΔP ≥ ΔP_allow 时按 ΔP_allow 计算。

3. 闪蒸与空化

P2 < Pv → 闪蒸；未闪蒸但已达阻塞差压 → 空化（缩流断面压力降至 Pv）。两者均需更换材质或调整工艺。

4. 气体 / 蒸汽

Cv = W / (N6·Y·√(x·P1·ρ1))，Y = 1 − x/(3·Fγ·xT) ≥ 0.667，Fγ = γ/1.4，阻塞判据 x ≥ Fγ·xT。xT 取阀门样本值（直通单座阀典型 0.7）。

5. 开度校核

线性特性 Cv(h)=Cvr·h；等百分比 Cv(h)=Cvr·50^(h−1)。本式为行业经验简化估算，未经标准核对，精确选型请用制造商流量特性表。建议工作开度 20%~80%。

6. 物性数据

Pv、Pc 请查《化学工程手册》或 NIST 数据库；本工具不内置介质库，避免使用未经核对的近似物性。
