O 形圈沟槽尺寸计算器

ISO 3601-2 / GB/T 3452.3 沟槽设计思路 · 压缩率 / 拉伸率 / 填充率校核














计算模型


压缩率 c 取推荐区间中值；槽深 t = d2×(1−c)；槽宽 b = k×d2（可手工覆盖）；槽底直径 dg = D+2t（轴用）或 D−2t（孔用）；拉伸率 ε = (贴合直径−d1)/d1；填充率 F = (πd2²/4)/(t·b)。


参数出处


    

  • 沟槽尺寸体系、O 形圈截面系列：ISO 3601-2 与 GB/T 3452.3《液压气动用 O 形橡胶密封圈 沟槽尺寸》（真实标准，本工具按其设计思路建模，具体数值表请查标准原文）。
    • 

  • O 形圈内径与截面系列：GB/T 3452.1 / ISO 3601-1。
    • 

  • 压缩率区间、槽宽系数 k、填充率上限、拉伸率上限：本参数为行业经验值，未经标准逐项核对（取自《机械设计手册》O 形密封圈章节通行取值）。
    • 

  • 材料适用温度：各胶种公开物性典型值，本参数为行业经验值，实际以供应商数据表为准。
    • 

  • 挡圈建议（>10 MPa 加挡圈、>20 MPa 双侧挡圈）：手册推荐经验值。
    • 



使用提示


空值、非数字、≤0、超范围均给出中文提示，温度允许负值。结果供工程估算与快速校核，正式设计须以标准表格及实测为准。
