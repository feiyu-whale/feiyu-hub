使用说明

1. 蒸汽工况：填蒸汽主管压力 P1（表压）与疏水阀后回收管线背压 P2，有效压差 ΔP=P1−P2。P2 必须小于 P1，否则疏水阀无法排液。
2. 运行凝结水量 Qr：正常生产时的连续凝结水量，可由换热器热负荷 Q(kW)×3600/h_fg 估算，或由厂家样本给出。
3. 预热凝结水量 Q_pre：冷态启动时加热设备本体所需热量折算，Q_pre = m·c·ΔT·60/(h_fg·t)，m 为设备质量、c 为比热、t 为预热时间(min)。不考核预热时质量填 0。
4. 阀型系数 K：热动力式 1.6、浮球式 1.35、倒吊桶式 1.5、热静力式 2.2。该组系数综合考虑了阀型排量特性、背压限制与过冷排放差异，属行业经验值，未经标准核对，实际应以制造商排量样本为准。
5. 设计排量：Q_d = (Q_r + Q_pre)×K×SF，安全系数 SF 一般取 1.2~1.5，启动频繁或负荷波动大时取上限。
6. 选型：按 Q = C_dn·√ΔP 计算各公称口径的排量，取第一个满足 Q_d 的最小口径。C_dn 容量系数为包络性工程近似值，本参数为行业经验值，未经标准核对。
7. 蒸汽物性：饱和温度与汽化潜热取自饱和水蒸气热力性质表（通用热工手册数据，1~25 bar(a) 区间线性插值），与 GB/T 系列水蒸气性质表附录数值一致。
8. 提示：热动力式疏水阀背压比不宜超过 50%，浮球式背压比可达 80%；过热蒸汽、排空气要求高或凝结水需回收至高位时，应另行校核。
