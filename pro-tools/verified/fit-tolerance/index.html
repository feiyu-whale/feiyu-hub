使用说明与数据来源


1 输入　基本尺寸 D（0~250 mm）、配合制（基孔制／基轴制）、孔与轴公差带代号及公差等级，点击「计算」。


2 输出　孔／轴上下偏差（μm）、极限尺寸（mm）、最大/最小间隙或过盈（μm）、配合性质判定与基准制。


3 判定规则（GB/T 1801-2009）　Xmax = ES − ei，Xmin = EI − es；Xmin ≥ 0 为间隙配合，Xmax ≤ 0 为过盈配合，其余为过渡配合；过盈量 Ymax = es − EI，Ymin = ei − ES。


4 数据来源　标准公差数值取自 GB/T 1800.1-2009《极限与配合 基础 第1部分：公差、偏差和配合的基础》标准公差数值表（IT6~IT11，≤250 mm）；轴基本偏差 d/e/f/g/h、k/m/n/p 与孔基本偏差 D/E/F/G/H 取自 GB/T 1800.2-2009《第2部分：标准公差带代号和孔、轴的极限偏差表》。


5 适用范围与限制　仅覆盖基本尺寸 0~250 mm、IT6~IT11 及上述公差带代号；J、R、S、T 等代号未收录，请查标准原表。结果按基本尺寸计算极限偏差，未计入形状位置误差、材料与温度影响，重要配合须以标准原表复核。
