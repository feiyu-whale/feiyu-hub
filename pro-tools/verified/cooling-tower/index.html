使用说明与依据



1. 适用范围


本工具用于机械通风式开式冷却塔（逆流式 / 横流式）的初步选型水量平衡计算：逼近度、冷幅、循环水量、蒸发损失、风吹损失、排污量与补水量。不含塔体填料容积、淋水密度、风机功率的详细热力校核（需用 Merkel 法逐段积分或厂商选型软件）。



2. 计算公式




项目公式说明


冷幅 ΔTΔT = t₁ − t₂进、出水温差，°C


逼近度 AA = t₂ − τ出水温度与湿球温度之差，°C


冷却塔效率 ηη = ΔT / (ΔT + A) = (t₁−t₂)/(t₁−τ)无量纲，反映塔接近理论极限的程度


循环水量 GG = Q×3600 / (Cp×ρ×ΔT)m³/h；Q 单位 kW


蒸发损失 EE = G×ΔT×Cp / rm³/h；热平衡法


风吹损失 DD = G × δδ 为风吹损失率，%


排污量 BDBD = E /(N−1) − D（下限取 0）溶解性固体质量平衡


补水量 MM = E + D + BD水量平衡





3. 参数取值与出处




参数取值出处 / 说明


水比热容 Cp4.1868 kJ/(kg·K)水的标准物性值，常压下 0~100 °C 区间可视为常数


水密度 ρ1000 kg/m³同上，工程近似值


汽化潜热 r2430 kJ/kg按约 30 °C 饱和水汽化潜热取值（0~100 °C 区间约 2500~2257 kJ/kg），本项为工程近似


浓缩倍数 N1.2 ~ 12GB 50050-2017《工业循环水冷却设计规范》：浓缩倍数应按水质稳定处理方案与补充水水质确定


风吹损失率 δ0.005% ~ 0.1%GB/T 7190.1-2008《机械通风冷却塔 第1部分：中小型开式冷却塔》对漂水率有限值要求；具体数值应按产品样本或验收实测值取用，本项下拉列表为工程常用经验取值，未经标准逐项核对


逼近度 A常规 3 ~ 5 °C本参数为行业经验值，未经标准核对；逼近度小于 3 °C 时塔体体积与造价急剧上升


水量平衡模型—《给水排水设计手册》第 4 册（工业给水处理）循环冷却水系统水量平衡；Merkel 热力计算法





4. 输入校验规则


    

  • 所有输入不得为空、不得为负、不得超出界面提示范围，否则显示中文错误提示。
    • 

  • 必须满足 t₁ > t₂ > τ，否则冷幅或逼近度不为正，塔无法完成该冷却任务。
    • 

  • 浓缩倍数 N 必须大于 1，否则排污量公式无意义（N=1 表示不浓缩，无排污）。
    • 

  • 当风吹损失过大导致 BD 计算为负时，程序取 0 并给出提示。
    •
